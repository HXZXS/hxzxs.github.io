# hxzxs.github.io

我的个人主页，托管在 GitHub Pages。

访问地址：<https://hxzxs.github.io>

## 技术栈

- HTML / CSS / JavaScript 手写，无框架、无外部依赖
- 单页结构，滚动显现动画
- 深色主题

## 本地预览

直接用浏览器打开 `index.html` 即可，或者起一个本地静态服务：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 修改

- 个人介绍在 `index.html` 的“关于我”区块，按真实情况替换
- 技能、项目、联系方式同理，直接改对应区块即可
- 改完推到 `main` 分支，GitHub Pages 会自动重新部署
